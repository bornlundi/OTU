## 1. General course summary

This course introduces programming and computational science using Python. It focuses on solving problems with computers, storing and retrieving data, algorithms, data structures, functions, object-oriented programming, data visualization, and simulations.

By the end of the course, students should be able to:

- Write Python programs using common programming constructs.
- Develop strategies for solving computational problems.
- Plot scientific data.
- Generate data using deterministic and stochastic simulations.

## 2. Core topics

1. Basic Python programming
2. Conditionals, loops, and lists
3. Functions, function calls, and argument passing
4. Data analysis and plotting
5. Stochastic and other simulations

## 4. Week-by-week plan

> The outline lists the major topics but does not give a complete dated lecture calendar. This plan provides a logical progression; use Canvas for the exact weekly module and lab.

### Week 1 — Python environment and basic syntax
**Study**
- Running Python code.
- Variables and assignment.
- Numbers, strings, and Boolean values.
- Expressions, operators, and output.
- Basic input and type conversion.

**Do**
- Set up the required coding environment.
- Work through introductory Thinkcspy material.
- Complete Lab 1 and the relevant module quiz.
- Practise short programs from scratch.

**Expect**
- Small coding tasks and syntax mistakes that require debugging.

### Week 2 — Conditionals and decision-making
**Study**
- Comparison and logical operators.
- `if`, `elif`, and `else`.
- Nested decisions.
- Boolean expressions.

**Do**
- Write programs that classify values or make decisions.
- Trace code by hand.
- Complete Lab 2 and the module quiz.

**Expect**
- Questions asking what a program prints or which branch executes.

### Week 3 — Loops
**Study**
- `for` loops.
- `while` loops.
- Loop counters and accumulators.
- Nested loops.
- Common infinite-loop errors.

**Do**
- Write counting, summing, and searching programs.
- Practise tracing loops.
- Complete Lab 3.

**Expect**
- Code-tracing and problem-solving exercises.

### Week 4 — Lists and data collections
**Study**
- Creating and indexing lists.
- Slicing.
- Updating lists.
- Iterating over collections.
- Basic list methods.

**Do**
- Solve problems involving lists of measurements or observations.
- Practise indexing and off-by-one errors.
- Complete Lab 4.

**Expect**
- Practical data-manipulation tasks.

### Week 5 — Functions
**Study**
- Defining and calling functions.
- Parameters and arguments.
- Return values.
- Local variables and scope.
- Decomposition of a problem into smaller functions.

**Do**
- Refactor long programs into functions.
- Write functions with clear names and documentation.
- Complete Lab 5.

**Expect**
- Problems requiring reusable code rather than one long script.

### Week 6 — Function calls and argument passing
**Study**
- Positional and keyword arguments where assigned.
- Return-value flow.
- Mutable versus immutable values at an introductory level.
- Testing functions.

**Do**
- Trace nested function calls.
- Write test cases for functions.
- Review material for Test 1.

**Expect**
- Theoretical questions and code tracing.

### Week 7 — Test 1 and introductory data analysis
**Study**
- Review basic syntax, conditionals, loops, lists, and functions.

**Do**
- Write programs without copying examples.
- Complete the theoretical Test 1 on October 19.
- Start Assignment 1 preparation.

**Expect**
- Test 1 emphasizes theoretical exercises.

### Week 8 — Scientific data and plotting
**Study**
- Representing data in Python.
- Plotting scientific data.

**Do**

- Explain what a graph shows.
- Complete the assigned lab and module quiz.

**Expect**

### Week 9 — Data processing and debugging
